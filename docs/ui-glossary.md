# Glosario de la interfaz

Términos que ve el usuario en la app en español. El diseño de Figma usa los términos originales en inglés y "Game'ya". Decisión de producto del 9 de noviembre de 2026.

| Concepto                          | En la interfaz               | No usar                 |
| --------------------------------- | ---------------------------- | ----------------------- |
| Grupo de ahorro por turnos        | **junta**                    | círculo, Game'ya        |
| Monto total que recibe un miembro | **pozo**                     | payout                  |
| Monto elegido al unirse           | **monto a recibir**          | monto de payout         |
| Mes en que se recibe el pozo      | **mes de cobro**             | mes de payout           |
| Costo de los primeros turnos      | **costo por turno**          | fees                    |
| Turno sin costo extra             | **sin costo adicional**      | sin fees                |
| Tipo de turno con menor costo     | **menor costo**              | menos fees              |
| Comisión de la cooperativa        | **gastos de administración** | Admin Fees              |
| Pago mensual                      | **cuota**                    | pay-in                  |
| Posición en la junta              | **turno**                    | slot                    |
| Requisitos para recibir el pozo   | **requisitos para cobrar**   | elegibilidad del payout |

- Descontar la cuota del mes de cobro se llama **"Pagar mi cuota con el pozo"**.
- El programa de ahorro con cashback es un **plan de ahorro**, no una junta.
- El código, la API y la documentación técnica siguen usando `circle`, `payout`, `fee` y `slot`. El glosario aplica solo a los textos visibles.
- La app no muestra los mensajes del backend: traduce cada error con sus propios textos.

  - Actualizar Figma con estos términos.
  - En inglés solo se reemplazó "Game'ya" por "circle".
